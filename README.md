# 카테고리별 넷플릭스 콘텐츠 찾기

TMDB(The Movie Database) API를 통해 **실제 영화·시리즈 데이터**와 **국가별 넷플릭스 제공 여부**를 실시간으로 불러와 카테고리별로 조회하는 웹앱입니다. 빌드 없이 순수 HTML/CSS/JS로 작성되었습니다.

## 왜 TMDB인가

넷플릭스는 카탈로그를 조회할 수 있는 공식 공개 API를 제공하지 않습니다. 대신 TMDB가 JustWatch로부터 제휴받은 **국가별 스트리밍 제공처(watch/providers) 데이터**를 무료 API로 공개하고 있어, 이 앱은 TMDB의 `discover` API를 "국가(watch_region) + 넷플릭스(provider 8) + 정액제(flatrate)" 조건으로 조회해 **그 나라 넷플릭스에 실제로 올라와 있는 콘텐츠**를 보여줍니다.

## 실행 방법

1. [themoviedb.org](https://www.themoviedb.org/signup)에서 무료 가입
2. 설정(Settings) → API 메뉴에서 **API Read Access Token (v3 auth)** 발급
3. 앱 실행 후 뜨는 안내 화면에 토큰 붙여넣기 (브라우저 `localStorage`에만 저장되고 어디로도 전송되지 않습니다. 코드나 저장소에는 절대 커밋하지 마세요.)

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

> Claude 아티팩트(claude.ai) 미리보기에서는 외부 API 호출이 차단되어 있어 이 버전은 동작하지 않습니다. 로컬 서버 또는 GitHub Pages 등 직접 배포한 환경에서 실행해야 합니다.

## 기능

- **국가 선택**: 상단 드롭다운으로 국가를 바꾸면 그 나라 넷플릭스 카탈로그 기준으로 목록이 다시 조회됩니다.
- **카테고리 필터**: 넷플릭스의 실제 대분류 장르에 최대한 맞춘 카테고리 칩 (매핑표는 아래 참고).
- **한국 콘텐츠**: 제작 국가가 한국인 작품만 모아보기.
- **19금**: 국가별 등급 기준(청소년 관람불가 등)으로 영화만 필터링. 등급 체계 미지원 국가는 안내 메시지가 뜹니다.
- **검색**: 현재 불러온 목록 안에서 제목/줄거리로 필터링합니다. (TMDB에 넷플릭스 제공 여부까지 반영한 전체 검색 API가 없어, 이미 불러온 카테고리 결과 내 검색으로 제한됩니다.)
- **상세 모달**: 실제 포스터/배경, 줄거리, 장르, 평점, 그리고 **이 작품이 넷플릭스로 제공되는 모든 국가 목록**.

## 알려진 한계

- 검색은 이미 불러온 카테고리 결과 안에서만 동작합니다.
- 공포/로맨스/음악/예능 카테고리는 TMDB 장르 체계 제약으로 영화 또는 시리즈 한쪽만 표시됩니다.
- 19금 필터는 TMDB가 지원하는 국가별 등급 문자열이 있는 나라에서만 동작합니다.
