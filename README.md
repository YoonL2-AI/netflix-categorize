# 카테고리별 넷플릭스 콘텐츠 찾기

넷플릭스 콘텐츠를 카테고리(장르)별로 조회하고 검색할 수 있는 정적 웹앱입니다. 별도 빌드 없이 순수 HTML/CSS/JS로 작성되었습니다.

## 실행 방법

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 기능

- 카테고리(장르) 칩 클릭으로 필터링
- 제목/줄거리 검색
- 카드 클릭 시 상세 정보 모달

## 데이터 수정

`data/contents.json` 파일을 편집해 콘텐츠 목록을 추가/수정할 수 있습니다.
