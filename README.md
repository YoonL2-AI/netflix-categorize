# 카테고리별 넷플릭스 콘텐츠 찾기

TMDB(The Movie Database) API를 통해 **실제 영화·시리즈 데이터**와 **국가별 넷플릭스 제공 여부**를 실시간으로 불러와 카테고리별로 조회하는 웹앱입니다. 빌드 없이 순수 HTML/CSS/JS로 작성되었습니다.

## 왜 TMDB인가

넷플릭스는 카탈로그를 조회할 수 있는 공식 공개 API를 제공하지 않습니다. 대신 TMDB가 JustWatch로부터 제휴받은 **국가별 스트리밍 제공처(watch/providers) 데이터**를 무료 API로 공개하고 있어, 이 앱은 TMDB의 `discover` API를 "국가(watch_region) + 넷플릭스(provider 8) + 정액제(flatrate)" 조건으로 조회해 **그 나라 넷플릭스에 실제로 올라와 있는 콘텐츠**를 보여줍니다.

## 실행 방법

1. [themoviedb.org](https://www.themoviedb.org/signup)에서 무료 가입
2. 설정(Settings) → API 메뉴에서 **API Read Access Token (v3 auth)** 발급
3. 앱 실행 후 뜨는 안내 화면에 토큰 붙여넣기 (브라우저 `localStorage`에만 저장되고 어디로도 전송되지 않습니다. 코드나 저장소에는 절대 커밋하지 마세요.)

키는 브라우저별로 따로 저장되므로 다른 기기/브라우저에서는 다시 입력해야 합니다. 매번 다시 붙여넣기 번거롭다면, 설정(⚙) 모달 안의 **"이 기기의 키로 링크 복사하기"** 버튼으로 `#key=...`가 담긴 링크를 만들 수 있습니다. 이 링크를 본인만 보는 메모 앱 등에 저장해두고 새 기기에서 한 번 열면 자동으로 키가 저장되고 주소창에서 즉시 사라집니다. 쿼리스트링(`?key=`)이 아니라 URL 프래그먼트(`#key=`)라서 서버 로그에는 남지 않지만, 브라우저 히스토리에는 남을 수 있으니 링크 자체를 다른 사람과 공유하지는 마세요.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

> Claude 아티팩트(claude.ai) 미리보기에서는 외부 API 호출이 차단되어 있어 이 버전은 동작하지 않습니다. 로컬 서버 또는 GitHub Pages 등 직접 배포한 환경에서 실행해야 합니다.

## 기능

- **국가 선택**: 로고 옆 "available in" 드롭다운으로 국가를 바꾸면 그 나라 넷플릭스 카탈로그 기준으로 목록이 다시 조회됩니다. 국가 이름 표기(대한민국/South Korea/韓国 등)와 정렬 순서는 `Intl.DisplayNames`를 통해 현재 Languages 설정을 따라갑니다.
- **3단계 카테고리 (대분류 → 중분류 → 소분류)**: 넷플릭스가 실제로 쓰는 장르 구조를 최대한 가깝게 재현했습니다. 예: `액션 & 모험`(대분류) → `액션 & 모험 전체`(중분류) → `슈퍼히어로`(소분류).
- **한국 콘텐츠**: 한국 드라마 / 한국 영화 / 한국 예능으로 나눠 제작 국가가 한국인 작품만 모아보기.
- **성인 등급**: 국가별 등급 기준(청소년 관람불가 등)으로 영화만 필터링. 등급 체계 미지원 국가는 안내 메시지가 뜹니다.
- **검색 (전체 카테고리 대상)**: 현재 선택된 카테고리와 무관하게 TMDB `/search/movie`, `/search/tv`로 카탈로그 전체를 검색한 뒤, 그중 현재 국가 넷플릭스에 정액제로 올라와 있는 항목만 걸러서 보여줍니다. 입력을 멈추고 약 0.45초 뒤 자동 검색되고(디바운스), 국가·콘텐츠 유형 필터를 바꾸면 검색도 그 조건으로 다시 실행됩니다. 카테고리 칩을 클릭하면 검색은 자동으로 해제되고 카테고리 탐색으로 돌아갑니다.
- **상세 모달**: 실제 포스터/배경, 줄거리, 장르, 평점, 그리고 **이 작품이 넷플릭스로 제공되는 모든 국가 목록**.
- **언어 선택 (Languages)**: 헤더 드롭다운(한국어/English/日本語/中文/Español/Français/Deutsch/Português/Tiếng Việt/Bahasa Indonesia)으로 목록 카드 제목과 상세 모달의 제목·줄거리·장르명을 TMDB가 지원하는 언어로 바꿔 볼 수 있습니다. 언어를 바꾸면 목록을 다시 불러옵니다. 선택한 언어로 된 줄거리가 TMDB에 없으면 영어 원문으로 자동 대체하고 안내 문구를 표시합니다. **대분류/중분류/소분류 카테고리 이름, 콘텐츠 유형 필터, 국가 드롭다운, 그리고 영화/시리즈 배지·러닝타임·"넷플릭스 제공 국가" 문구·검색창 placeholder·빈 결과/로딩/더보기 문구까지 전부 같은 언어로 함께 바뀝니다** (TMDB 데이터가 아니라 앱에 내장된 자체 번역 사전 `CATEGORY_I18N`/`UI_I18N`을 씁니다). TMDB API 키 발급 안내 모달만 아직 한국어 고정입니다.
- **콘텐츠 유형 필터**: "전체 콘텐츠 / 영화만 / 시리즈만" 라디오 버튼으로 목록을 좁힙니다. 선택한 유형을 아예 제공하지 않는 카테고리(예: 공포는 영화만 제공)에서 "시리즈만"을 고르면 안내 메시지가 뜹니다.
- **콘텐츠 개수 표시**: 지금까지 불러온 개수가 아니라 TMDB가 알려주는 해당 카테고리의 **전체 개수**를 "총 N개 중 M개 불러옴" 형태로 보여줍니다.

## 카테고리 구조는 어떻게 만들어졌나

넷플릭스의 실제 내부 장르 코드(예: `browse/genre/1365`)는 공개 API가 아니라 웹 UI에만 존재해서 프로그램이 직접 조회할 수 없습니다. 대신 이 앱은 **TMDB가 제공하는 진짜 필터**를 조합해 넷플릭스 화면의 대분류/중분류/소분류 구조를 재현합니다.

- **대분류·중분류**: TMDB 공식 장르 ID(`with_genres`)를 조합. 예: `SF & 판타지` = 영화 장르 878(SF)+14(판타지), 시리즈 장르 10765.
- **소분류**: 아래 중 하나로 상위 필터를 더 좁힙니다.
  - **키워드**: TMDB `/search/keyword`로 실시간 검색해 실제 존재하는 키워드 ID를 찾아 `with_keywords`에 사용 (예: "무술 영화" → `martial arts` 검색 → 매칭 ID). 하드코딩된 가짜 ID가 아니라 매 요청 시 TMDB에서 실제로 조회합니다.
  - **추가 장르**: 예) 코미디 중분류 아래 "로맨틱 코미디" 소분류는 코미디 장르에 로맨스 장르(10749)를 더함.
  - **제작 국가 / 개봉 연도 범위**: 예) "일본 애니메이션"은 `with_origin_country=JP`, "2020년대 신작"은 `primary_release_date.gte=2020-01-01`.

대분류 목록: **전체 콘텐츠**(장르 제한 없이 이 국가 넷플릭스 전체), 액션 & 모험, 코미디, 드라마, 공포, 로맨스, SF & 판타지, 스릴러 & 미스터리, 범죄, 다큐멘터리, 애니메이션, 키즈 & 가족, 한국 콘텐츠, 예능 & 리얼리티, 음악 & 뮤지컬, 성인 등급. 첫 화면 기본값도 "전체 콘텐츠"입니다. 전체 트리 구조는 `js/app.js`의 `TAXONOMY` 상수에 정의되어 있습니다.

## 알려진 한계

- 검색은 후보를 미디어 타입별로 상위 20개까지만 확인합니다(그 이상은 아직 지원하지 않음). 검색 결과 자체는 TMDB의 관련도 순서를 그대로 따릅니다.
- 공포/로맨스/음악/스탠드업/예능은 TMDB 장르 체계 제약으로 영화 또는 시리즈 한쪽만 표시됩니다.
- 성인 등급 필터는 TMDB가 지원하는 국가별 등급 문자열이 있는 나라에서만 동작합니다.
- 소분류의 키워드 검색은 TMDB 키워드 데이터베이스에 매칭되는 항목이 없으면 조용히 상위 필터로 되돌아갑니다(빈 결과가 나올 수 있음).
